# Brish - Planificador & Organizador Personal Android

Brish es una aplicacion movil nativa para Android diseñada para la gestion integral de productividad personal, planificacion diaria, seguimiento gamificado de habitos y trabajo enfocado.

## Caracteristicas Principales

- **Planificador & Mi Agenda:** Organizador diario con selector de fechas y gestion de tareas por prioridad.
- **Seguimiento de Habitos:** Sistema gamificado con contadores de racha activa y metas progresivas.
- **Modo Enfoque (Pomodoro):** Temporizador de concentracion configurable con interfaz oscura optimizada.
- **Coach Virtual e Integracion de IA:** Asistente integrado para recomendaciones motivacionales y organizativas.
- **Privacidad:** Datos almacenados de forma segura con politicas estrictas de proteccion de usuario.
